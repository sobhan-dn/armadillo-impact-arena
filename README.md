# Armadillo: Impact Arena

Standalone playable release of Armadillo: Impact Arena.

Play: https://sobhan-dn.github.io/armadillo-impact-arena/

This repository contains the complete production release, including local fonts, physics engine, icons, and offline cache. GitHub Pages serves it directly from the main branch. No API keys, external game server, Render, Firebase, or running local computer is required.

## Controls

Move: A/D or arrow keys. Jump: W/Up. Hold Space to curl and catch; release to launch in the last movement direction. Touch controls are included.
